TrailBound is an expedition planning website where a user can create a new expedition, fill the details like date, number of people, duration, etc and it opens a checklist with a few basic and common supplies. User can add their own planned items to the checklist. Progress bar shows how many they have clicked and how many are left. A food and water supply calculator is also added so that the user knows aprox how much to carry in a general situation.

Tech Stack: HTML, CSS and JS

Built as a project for Hack Club's Survive YSWS [You Ship We Ship] Program.
